# 🚀 SahyogAI

**SahyogAI** is a full-stack AI-powered career development platform designed to help students and professionals navigate their career journey through personalized guidance, AI-generated career resources, interview preparation, and real-time industry insights.

Built with modern web technologies and powered by Large Language Models, SahyogAI acts as an intelligent career companion that assists users from exploration to job readiness.

---

## ✨ Features

### 🎯 Personalized Career Guidance

* AI-powered career insights based on user profile, skills, and interests
* Personalized recommendations by selecting your industry and expertise
* Actionable suggestions to improve career growth

### 📄 AI Resume & Cover Letter Generator

* Generate **ATS-optimized resumes**
* Create compelling AI-powered cover letters
* Save resumes and cover letters for future use
* Export documents as **PDF**

### 🎤 AI Mock Interview Quizzes

* Practice role-specific mock interview questions generated by AI
* Receive intelligent feedback on responses
* Improve communication and technical interview skills

### 📊 Performance Analytics

* Track interview performance over time
* View detailed improvement analytics
* Identify strengths and areas requiring improvement

### 📈 Industry Insights

* Stay updated with current industry trends
* Explore salary insights and market demand
* Access AI-generated career and hiring analysis

### 🔒 Authentication & User Profiles

* Secure authentication using Clerk
* Personalized onboarding experience
* Persistent user profile and career preferences

## ⚙️ Installation

```bash
git clone <repository-url>

cd sahyogai

npm install

npm run dev
```

Set up Environment Variables:
Create a .env file in the root directory and add the following keys. You will need to obtain these from their respective platforms (Clerk, Neon, Gemini, Inngest).

Visit:

```
http://localhost:3000
```
